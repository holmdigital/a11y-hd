```typescript
describe('AccessibilityStatement locale routing', () => {
    Object.entries(LOCALE_TITLE_MARKERS).forEach(([locale, expectedMarker]) => {
        it(`renders ${locale} locale with correct title marker`, () => {
            const { container } = render(
                <AccessibilityStatement {...defaultProps} locale={locale} />
            );
            const html = container.innerHTML;
            expect(html).toContain(expectedMarker);
        });
    });
});
```

Each test:
1. Renders `<AccessibilityStatement {...defaultProps} locale={locale} />`
2. Gets `container.innerHTML` as a string
3. Asserts `expect(html).toContain(expectedMarker)` -- the locale-specific title substring

This proves each locale routes to its unique template, not to English fallback.

**describe('AccessibilityStatement placeholder leakage', ...)** -- TEST-04:

A parametrized test iterating all 9 locales. All optional props are provided via `defaultProps` to exercise every placeholder substitution path:

```typescript
describe('AccessibilityStatement placeholder leakage', () => {
    const locales = ['sv', 'en', 'no', 'da', 'de', 'fr', 'es', 'fi', 'nl'];

    locales.forEach((locale) => {
        it(`no {<...>} placeholders survive in ${locale} locale output`, () => {
            const { container } = render(
                <AccessibilityStatement {...defaultProps} locale={locale} />
            );
            const html = container.innerHTML;
            expect(html).not.toMatch(PLACEHOLDER_PATTERN);
        });
    });
});
```

Each test:
1. Renders with ALL optional props provided (phoneNumber, responseTime, assessmentDate, publishDate, evaluationMethod, generatorTool, nonComplianceItems)
2. Gets `container.innerHTML`
3. Asserts `expect(html).not.toMatch(/\{<[^>]+>\}/)` -- no `{<...>}` placeholder patterns survive

This catches any placeholder that was missed in the replacements map for any locale.

**Important details:**
- Do NOT use `vi.mock()` -- no module mocking needed
- Do NOT import `beforeEach` or `afterEach` -- tests have no shared mutable state
- The `.tsx` extension is required because the test uses JSX (`<AccessibilityStatement ... />`)
- Use `toContain` for string assertions (not `toHaveTextContent` from jest-dom which is NOT installed)
- Use `toMatch` with regex for placeholder leakage (not `toContain`)
