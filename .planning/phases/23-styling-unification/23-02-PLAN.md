<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| consumer style props → rendered element | Consumer-supplied `className` and `style` props pass through to React DOM; React JSX escapes string values |
| consumer custom-property overrides → component visuals | Consumer overrides `--hd-tabs-*` via their own `:root` rule; cascade is the only interface |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-02-01 | Tampering | Consumer-supplied `className` passthrough | accept | React JSX escapes strings; current Tabs already accepts this — no new attack surface (RESEARCH.md Security Domain) |
| T-23-02-02 | Information Disclosure | CSS custom-property override | accept | Custom properties cannot break out of CSS rule value context (standard browser behavior); consumer cannot inject script via `--hd-tabs-active-color` |
| T-23-02-03 | Repudiation | Keyboard focus indicator regression | mitigate | `:focus-visible` smoke test asserts the selector is present in `Tabs.css`; CI fails if a future refactor drops it (WCAG 2.4.7 / STY-04) |
| T-23-02-04 | Tampering | Active-tab style hook regression | mitigate | New smoke test asserts `[aria-selected="true"]` attribute selector is present in `Tabs.css`; protects against future refactor accidentally dropping/typo'ing the active-state rule |
</threat_model>
