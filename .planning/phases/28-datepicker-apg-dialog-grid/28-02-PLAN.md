DatePicker.tsx state (from Plan 28-01):
- `isOpen: boolean` — popup open state
- `cursor: Date` — first-day-of-month for the currently-rendered calendar page
- `triggerRef: RefObject<HTMLButtonElement>`
- `popupRef: RefObject<HTMLDivElement>`

Plan 28-02 ADDS:
- `focusedDate: Date | null` — the cell carrying tabindex=0 (the rove anchor).
  Initial value when opening: `value ?? today ?? clampDate(today, minDate, maxDate)`.
- On open: useEffect imperatively focuses the cell matching `focusedDate`.
- On Escape: `setIsOpen(false)` + `triggerRef.current?.focus()`.
- On commit (Enter/Space/click on non-disabled cell): `onChange?.(cell)` + `setIsOpen(false)` + focus trigger.

APG keyboard matrix (from 24-RESEARCH §1, verified against W3C):
| Key                  | Action                                              |
|----------------------|-----------------------------------------------------|
| ArrowLeft / Right    | focusedDate ± 1 day                                 |
| ArrowUp / Down       | focusedDate ± 7 days                                |
| Home / End           | focusedDate → week start / week end (locale-aware)  |
| PageUp / PageDown    | focusedDate → addMonths(focusedDate, ∓1)            |
| Shift+PageUp / Down  | focusedDate → addMonths(focusedDate, ∓12)           |
| Enter / Space        | commit focusedDate (if not disabled)                |
| Escape               | close, no commit, return focus to trigger           |
| Tab / Shift+Tab      | cycle inside dialog (handled by useFocusTrap)       |

When arrow nav moves focusedDate outside the current cursor month, the cursor
advances/retreats so the new focusedDate is visible. When moved past minDate
or maxDate, the focus clamps at the bound (does NOT wrap, does NOT silently
move past — APG spec).

From src/_hooks/useFocusTrap.ts — read the file at execute-plan time to verify
the exact signature; Phase 22 established it. Engage it ONLY while `isOpen`
(typical pattern: pass `popupRef` and an `enabled` boolean).

       const onGridKeyDown = (e: React.KeyboardEvent<HTMLDivElement>) => {
           if (!focusedDate) return;
           let next: Date | null = null;
           switch (e.key) {
               case 'ArrowLeft':  next = addDays(focusedDate, -1); break;
               case 'ArrowRight': next = addDays(focusedDate,  1); break;
               case 'ArrowUp':    next = addDays(focusedDate, -7); break;
               case 'ArrowDown':  next = addDays(focusedDate,  7); break;
               case 'Home': {
                   // Jump to start of week (locale-aware weekStart)
                   const iso = ((focusedDate.getDay() + 6) % 7) + 1;
                   const back = (iso - weekStart + 7) % 7;
                   next = addDays(focusedDate, -back);
                   break;
               }
               case 'End': {
                   const iso = ((focusedDate.getDay() + 6) % 7) + 1;
                   const forward = (6 - ((iso - weekStart + 7) % 7));
                   next = addDays(focusedDate, forward);
                   break;
               }
               case 'PageUp':
                   next = e.shiftKey ? addMonths(focusedDate, -12) : addMonths(focusedDate, -1);
                   break;
               case 'PageDown':
                   next = e.shiftKey ? addMonths(focusedDate,  12) : addMonths(focusedDate,  1);
                   break;
               case 'Enter':
               case ' ':
               case 'Spacebar':
                   e.preventDefault();
                   commitFocused();
                   return;
               case 'Escape':
                   e.preventDefault();
                   closeAndReturnFocus();
                   return;
               default:
                   return;
           }
           if (next) {
               e.preventDefault();
               const clamped = clampDate(next, minDate, maxDate);
               setFocusedDate(clamped);
               // Advance cursor if the new focused date is outside the visible page
               if (clamped.getMonth() !== cursor.getMonth() || clamped.getFullYear() !== cursor.getFullYear()) {
                   setCursor(new Date(clamped.getFullYear(), clamped.getMonth(), 1));
               }
           }
       };
       ```

       const commitFocused = () => {
           if (!focusedDate) return;
           const clamped = clampDate(focusedDate, minDate, maxDate);
           if (!isSameDay(clamped, focusedDate)) return; // out-of-bound — no-op
           _onChange?.(clamped);
           setIsOpen(false);
           triggerRef.current?.focus();
       };
       const closeAndReturnFocus = () => {
           setIsOpen(false);
           triggerRef.current?.focus();
       };
       ```
