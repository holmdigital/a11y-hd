Phase 27 D-04 pattern (`hasInteracted` ref):
```typescript
const hasInteracted = useRef(false);
const [announcement, setAnnouncement] = useState<string>('');

// In the user-action handler (NOT in a mount-effect):
const handleCommit = (date: Date) => {
    hasInteracted.current = true;
    setAnnouncement(getDateAnnouncement(locale, date));
    // ... rest of commit logic
};
```

The ref is read-only "have we seen a user action yet?" gate; the announcement
state is what `LiveRegion` displays. Both pieces are needed: without the ref,
a `<LiveRegion message="">`-on-mount could announce empty; without the state,
no re-renders fire.

No debounce needed (selection is user-paced, not keystroke-paced — like
MultiSelect in Phase 27, not Combobox).
