<!-- Template structure — all 12 existing templates follow this exactly -->
JSON schema (6 sections, fixed section IDs):
```json
{
    "title": "...",
    "intro": "...",
    "sections": [
        { "id": "how-accessible", "title": "...", "content": "..." },
        { "id": "what-to-do",     "title": "...", "content": "..." },
        { "id": "reporting",      "title": "...", "content": "..." },
        { "id": "enforcement",    "title": "...", "content": "..." },
        { "id": "technical",      "title": "...", "content": "..." },
        { "id": "testing",        "title": "...", "content": "..." }
    ]
}
```

Template mechanics:
- {<placeholder>}          — substituted from the substitutions table
- { A / B / C }            — choice block resolved by complianceLevel (full=A, partial=B, non-compliant=C)
- [ ... ]                  — conditional block (kept or removed based on content type)
- Existing shared placeholders safe to use in all three templates:
    {<organisation>}        → organizationName
    {<enforcement_body>}    → getEnforcementBody(country, 'public')
    {<national_law>}        → getNationalLawByFramework('WAD', country) fullName + law code
    {<e-mail address>}      → contactEmail
    {<telephone number>}    → phoneNumber
    {<response time>}       → responseTime (inside [ ] conditional)
    {<assessment date>}     → assessmentDate ISO date
    {<publish date>}        → publishDate ISO date
    {<update date>}         → lastReviewDate ISO date
    {<method>}              → evaluationMethod string
    {<third party>}         → generatorTool.name
